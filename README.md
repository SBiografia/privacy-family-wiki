# FamilyWiki Calendar Sync — Public Information Pages

This public repository contains **only static informational pages** for the personal-use FamilyWiki Calendar Sync OAuth app:

- `index.html`: app home page and description
- `privacy.html`: privacy policy / Google Calendar API data usage
- `terms.html`: terms of service
- `styles.css`: site styling

It contains **no family wiki data, calendar events, server address, credentials, OAuth tokens, or private application source**.

## GitHub Pages

Publish from the `main` branch, `/(root)` folder under **Settings → Pages → Build and deployment → Deploy from a branch**.

Expected GitHub Pages address (once enabled):

`https://sbiografia.github.io/privacy-family-wiki/`

Policy and terms are at `privacy.html` and `terms.html` under the same path.

The pages are explanatory documents, not a public login endpoint or a release of the private app. Google OAuth domain verification and acceptance must be checked separately.
